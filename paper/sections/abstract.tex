\begin{abstract}
Reinforcement learning enables agents to acquire effective behaviour through
interaction with an environment. However, real-world agents meet tasks in
sequence, and learning a new one overwrites what earlier ones established.
Although Continual Reinforcement Learning addresses this, existing methods only
approximate retention, using a fixed penalty, a stored sample, or frozen
parameters. To address this, we propose Dual-Policy Expert-Anchored Learning
(DUEL), which trains a short-lived expert on each incoming task and anchors the
deployed policy to every expert it has seen. Specifically, the deployed policy
may never fall behind an expert, yet is never held back from surpassing one, so
earlier tasks can still improve. Additionally, the pressure applied for each
task adapts during training, concentrating effort where competence is being
lost, and DUEL stores no past experience, revisiting earlier environments
directly instead. Experiments on three settings show that DUEL matches
state-of-the-art methods on the established benchmark and pulls ahead wherever
the network cannot expand to give each task its own parameters. Across fifty
such tasks it improves average performance by 0.126 and ends 91\% of tasks above
their initial level, against 13\% for the nearest baseline. On five entirely
different Atari games, a regime the literature leaves largely untested, DUEL
alone retains the earlier games while still learning the last. The source code
will be released.
\end{abstract}

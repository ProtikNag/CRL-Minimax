\begin{abstract}
Reinforcement learning enables agents to master effective behavior through
interaction with an environment. However, real-world agents face tasks in
sequence, and learning a new one can reshape the behavior the agent had acquired
for earlier ones. Although Continual Reinforcement Learning addresses this,
retention is pursued indirectly in the current literature. Existing methods do
so by penalizing weight movement, imitating behavior from stored data, or
expanding the architecture. None of these makes performance on an old task a
constraint the agent is required to meet. We propose \textbf{Dual-Policy
Expert-Anchored Learning (DUEL)}, which trains a temporary expert on each new
task and requires the policy it deploys to keep scoring on that task as well as
the expert did. Specifically, the deployed policy is corrected only when it
scores below an expert and is never pulled back when it scores above, so a task
can keep improving after it is learned. On the established benchmark, DUEL
matches state-of-the-art methods, and it pulls ahead whenever the network cannot
expand to give each task its own parameters. Across fifty such tasks, it
improves average performance by $0.126$ and ends $91\%$ of tasks above their
initial performance, against $13\%$ for the nearest baseline. On five Atari
games with high task dissimilarity, a setting the literature rarely tests, DUEL
retains the earlier games while still learning the last, which no other
fixed-architecture method manages. The source code will be provided upon
acceptance of this work.
\end{abstract}

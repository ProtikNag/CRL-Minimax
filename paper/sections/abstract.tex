\begin{abstract}
Reinforcement learning enables agents to acquire effective behaviour through
interaction with an environment. However, real-world agents meet tasks in
sequence, and learning a new one destroys what earlier ones established.
Although Continual Reinforcement Learning addresses this, retention is pursued
indirectly, by penalising weight movement, imitating behaviour from stored data,
or freezing parameters per task. None of these makes performance on an old task
a level the agent is required to meet. We
propose Dual-Policy Expert-Anchored Learning (DUEL), which trains a temporary
expert on each new task, then requires the policy it deploys to keep scoring as
well on that task as the expert did. Specifically, the deployed policy is
corrected only when it scores below an expert and never pulled back when it
scores above, so a task can keep improving after it was learned. Additionally,
the correction grows with how far a task has fallen, so effort goes where ground
is being lost, and DUEL stores no past data, revisiting earlier environments
directly. On the established benchmark DUEL matches state-of-the-art methods,
and it pulls ahead wherever the network cannot expand to give each task its own
parameters. Across fifty such tasks it improves average performance by 0.126 and
ends 91\% of tasks above their initial level, against 13\% for the nearest
baseline. On five Atari games with high task dissimilarity, a setting the
literature rarely tests, DUEL alone retains the earlier games while still
learning the last. The source code will be released.
\end{abstract}
